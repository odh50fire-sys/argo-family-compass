# 🌟 ARGO - 우리 가족 생애 재설계 가치관 나침반

> **"가슴 뛰는 내면의 가치를 찾아 떠나는 온 가족의 인생 2막 항해"**  
> 아빠의 쉼(휴직), 엄마의 새출발(퇴직), 12세 쌍둥이 자녀(아들·딸)의 무한한 성장을 응원하는 가치관 기반 라이프 내비게이션 플랫폼입니다.

---

## 🧭 프로젝트 소개

ARGO는 단순한 성격 테스트가 아닌, **검증된 심리학·진로상담학·실존주의 철학**을 바탕으로 내면의 타협 불가능한 핵심 가치관을 발견하고, 이에 부합하는 **5대 영역 (직업, 공부, 취미, 여행지, 생활활동)**을 탐색하도록 돕는 플랫폼입니다.

### 📚 학술적·이론적 기반
* **샬롬 슈워츠(Shalom Schwartz)**: 보편적 인간 가치 이론 (10대 가치 체계 & 딜레마)
* **에드가 샤인(Edgar Schein)**: 경력 닻(Career Anchors) 모델
* **마크 사비카스(Mark Savickas)**: 진로 구성주의(Career Construction Theory)
* **미하이 칙센트미하이(Mihaly Csikszentmihalyi)**: 몰입(Flow) 최적 경험 이론
* **수용전념치료(ACT)**: 가치 기반 행동(Valued Living) 및 실존적 관점 전환

## 🎮 두 가지 진행 방식 (Dual Modes)

1. **🧘 솔로 심층 모드 (Solo Deep-Dive Mode)**
   * 나만의 조용한 시간과 공간에서 오롯이 깊은 내면을 성찰하는 1인 모드.
   * 4단계 딜레마 선택을 거쳐 개인별 핵심 가치 분석 및 5대 영역 심층 제안서 발급.

2. **👨‍👩‍👧‍👦 패밀리 서클 릴레이 모드 (Family Circle Relay Mode)**
   * 온 가족이 한 디바이스(스마트폰/태블릿/노트북)를 두고 번갈아 가며 진행하는 보드게임형 모드.
   * "스마트폰을 아빠에게 넘겨주세요! 🐻" 턴 전환 시스템과 가족 대화 가이드 제공.
   * 최종 완료 시 **「우리 가족 가치관 지도」**, **「우리 가족 삶의 헌장」**, **「공동 5대 버킷 프로젝트」** 완성.

## 📱 모바일 앱 & PWA 지원
* 작은 스마트폰 화면에서도 시원한 가독성을 제공하는 대형 폰트와 넉넉한 여백.
* 하단 탭 바 (홈 / 솔로 모드 / 패밀리 릴레이 / 가족 헌장) 한 손 조작 최적화.
* 스마트폰 브라우저에서 **「홈 화면에 추가」**를 누르면 앱스토어 설치 없이 네이티브 앱처럼 동작.

---

## 📂 파일 구조
* `index.html`: PC 및 데스크톱 반응형 웹 애플리케이션
* `mobile.html`: 스마트폰 화면 및 터치 조작에 최적화된 모바일 전용 앱
* `manifest.json`: 모바일 앱(PWA) 설치 설정 메타데이터
* `실행하기.bat`: 윈도우 환경에서 더블클릭으로 즉시 실행하는 런처

---

## 🚀 실행 방법
1. 로컬에서 실행: `실행하기.bat` 더블클릭 또는 `index.html`, `mobile.html` 브라우저 열기
2. GitHub Pages 배포 시: 웹 링크를 통해 스마트폰에서 즉시 접속 가능
